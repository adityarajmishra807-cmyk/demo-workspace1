# Phase 14A — Premium Section Library

## Status
Implemented on `main`.

## Purpose
Expand V2 from a small set of fixed compositions into a reusable library of premium section variants.

## Library

17 variants across hero, about, offerings, visual, trust, FAQ, location, conversion, and contact families.

## Selection

Variants are selected by section family and asset availability. Image-rich clients prefer image-required variants when available; sparse clients retain safe non-image variants.

## Design principle

The library provides structural variation without fabricating business facts. Later archetype composition can select and sequence these variants to create materially different websites.
